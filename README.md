
# Tic-Tac-Toe AI

A full-stack Tic-Tac-Toe game where a player can
play against an AI opponent.

## Technologies Used

### Frontend
- React.js
- Vite
- HTML, CSS, JavaScript

### Backend
- Python
- Flask
- REST API

### Artificial Intelligence
- Minimax Algorithm

## Features

- Player vs AI gameplay
- Intelligent AI opponent using Minimax
- Responsive user interface
- Score tracking
- Restart game functionality

## Project Structure

```text
Tic-Tac-Toe/
├── frontend/
├── backend/
├── docs/
├── .gitignore
└── README.md
```

## Installation and Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
python -m venv venv
```

Activate the virtual environment and install dependencies:

```bash
pip install -r requirements.txt
python app.py
```
